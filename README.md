# Vacancy Outreach Skill

Independent documentation for a Claude Code workflow that searches vacancies, prepares tailored messages and can submit applications through a third-party job-board interface. This repository is not affiliated with, endorsed by or operated by any job board or its rightsholders.

The repository contains a skill specification and design documents. It does not contain the runtime scripts, account access or credentials required to run the workflow. The documentation describes an existing site-specific integration and does not grant permission to access a website, collect its data or send messages through it.

## Use and limits

Before using any integration, check the site's current terms and obtain any required permission. Review each application before submission, use the service only for its intended purpose, and stop if access controls or rate limits block the workflow. The historical design notes below describe automation and are not a statement that it is currently authorized or active.
