# /vacancy-outreach — подготовка и отправка откликов

Независимый проект; не связан с операторами сайтов вакансий. Перед использованием проверьте правила площадки и разрешения.

Полная спецификация: https://github.com/TimmyZinin/vacancy-outreach-skill/blob/main/SPEC.md

## Вызов

```
/vacancy-outreach <количество> [запрос] [--флаги]
```

## Аргументы

| Аргумент | Тип | Дефолт | Описание |
|----------|-----|--------|----------|
| количество | число | обязательный | Сколько откликов отправить |
| запрос | строка | "маркетолог OR SMM OR контент" | Поисковый запрос площадки |
| --query | строка | - | Альтернатива позиционному запросу |
| --period | число | 1 | Период поиска в днях |
| --min-salary | число | - | Минимальная зарплата |
| --dry-run | флаг | - | Поиск + генерация БЕЗ отправки |
| --preview | флаг | - | Показать текст перед каждой отправкой |
| --any-format | флаг | - | Не фильтровать по удалёнке |
| --no-filter | флаг | - | Отключить exclusion фильтр |

## Процесс

### Шаг 0: INIT
1. Каталог данных: `~/hh-outreach-data/` (прежнее имя сохранено для совместимости). Прочитать в нём `sent.json`
   - Если файл corrupted: восстановить из `.bak` или создать пустой
   - Валидация: JSON парсится, поле `vacancies` - массив, каждый элемент имеет `id` и `status`
   - Дедупликация: убрать записи с одинаковым `id`
2. Backup: `cp sent.json sent.json.bak`
3. Проверить лимит: если vacancies.length > 150 - показать предупреждение, если > 180 - запросить подтверждение
4. Парсить аргументы (количество, запрос, флаги)
5. CDP healthcheck:
   ```bash
   CDP=~/.claude/skills/chrome-cdp/scripts/cdp.mjs
   NODE=~/.nvm/versions/node/v22.22.1/bin/node
   $NODE $CDP list
   ```
   - Если ошибка "Daemon failed" - сообщить: "CDP недоступен. Открой chrome://inspect и включи remote debugging."
   - Найти вкладку площадки из URL ниже или открыть новую

### Шаг 1: SEARCH
1. Построить URL:
   ```
   https://hh.ru/search/vacancy?text={QUERY}&order_by=publication_time&search_period={PERIOD}&items_on_page=20&page={PAGE}
   ```
   - Добавить `&schedule=remote` если НЕ --any-format
   - Добавить `&salary={MIN_SALARY}` если указан --min-salary
2. Навигировать через `$NODE $CDP nav <tab> <url>` (timeout 15s)
3. Извлечь вакансии через `$NODE $CDP eval`:
   ```javascript
   var cards = document.querySelectorAll('a[data-qa="serp-item__title"]');
   // Для каждой: id, title, company
   ```
4. Фильтрация (если НЕ --no-filter):
   - Исключить если title содержит: Wildberries, WB, Ozon, продаж, рекрут, HR, недвижим, ассистент, Junior, Младший, стажёр, дизайнер, developer, разработчик, motion, Python, Java, бухгалтер
5. Дедупликация: исключить ID которые уже есть в sent.json
6. Пагинация: если набрано меньше нужного - page++, повторить
7. Если 0 результатов - показать "0 вакансий найдено", завершить

### Шаг 2: READ (для каждой вакансии)
1. `$NODE $CDP nav <tab> <vacancy_url>` (timeout 15s)
2. Извлечь через `$NODE $CDP eval`:
   - Название, компания, зарплата (raw), описание (первые 1000 символов)
3. Проверить "Вы откликнулись" - если да: SKIP_ALREADY_APPLIED
4. Парсинг зарплаты:
   - "от 100 000" → 100000
   - "до 150 000" → 150000
   - "от 100 до 150" → 125000 (среднее)
   - "$2 000" → 200000 (курс $1=100₽)
   - "€2 000" → 220000 (курс €1=110₽)
   - "gross" или "до вычета" → multiply 0.87
   - Не парсится → null

### Шаг 3: GENERATE
Сгенерировать кастомный текст по модульному шаблону:

**OPENING** (random из 5):
1. `Коллеги из {КОМПАНИЯ}, привет!`
2. `Привет, команда {КОМПАНИЯ}!`
3. `{КОМПАНИЯ}, привет!`
4. `Привет! Пишу по вашей вакансии {ДОЛЖНОСТЬ}.`
5. `Коллеги, привет!`

**VACANCY_REACTION:**
`Насколько я понимаю, вы ищете {ПЕРЕСКАЗ - 1-2 предложения на основе описания}`

**OFFER** (если зарплата есть):
`У меня есть предложение получше. Вместо найма в штат предлагаю поработать на подряде - оплата на моё ИП, {SALARY*0.8} вместо {SALARY}.`

**OFFER** (если зарплаты нет):
`У меня есть предложение получше. Вместо найма в штат предлагаю поработать на подряде - оплата на моё ИП, на 20% дешевле чем штатный сотрудник с налогами.`

**WHAT_I_DO** (match по ключевым словам):
| Ключевые слова | Текст модуля |
|---------------|-------------|
| SMM, соцсети, контент-план | AI-контент-завод генерит посты, визуалы, публикует на все площадки автоматически |
| лидогенерация, B2B, трафик | Лид-машина автоматически находит клиентов, обогащает контакты, генерит предложения |
| воронки, автоворонки, email | Вебинарные воронки с автоматическими прогревами, квалификация лидов |
| SEO, контент-маркетинг | AI генерит экспертные тексты под семантическое ядро, публикует |
| CRM, retention, рассылки | AI автоматизирует сегментацию, персональные письма, триггерные цепочки |
| видео, reels, YouTube | AI-видеопайплайн: HeyGen, ElevenLabs, автоматическая нарезка |
| блогеры, influencer | AI ищет блогеров, генерит ТЗ, отслеживает результаты |

**SLOTS:**
`Я работаю как удалённый подрядчик. Беру до 5 клиентов одновременно, сейчас у меня есть 2 свободных слота.`

**CTA:**
```
Кейсы: timzinin.com
Поговорить: calendly.com/timzinin
```

**Anti-AI правила:**
- Без тире (—), только дефис с пробелами ( - )
- Без слов: инновационный, комплексный, синергия, оптимизация
- Без hedge words: возможно, наверное, может быть
- Без passive voice
- Компактные абзацы

### Шаг 4: SEND
1. Если --dry-run: показать текст, записать SKIP_DRY_RUN, перейти к следующей
2. Если --preview: показать текст, спросить OK/Skip
   - Skip → записать SKIP_USER
3. DOM-based клики (ВСЕ через eval по textContent, НЕ clickxy):
   ```javascript
   // Откликнуться
   eval "var btns = document.querySelectorAll('a, button');
   for (var i = 0; i < btns.length; i++) {
     if (btns[i].textContent.trim() === 'Откликнуться') {
       var rect = btns[i].getBoundingClientRect();
       if (rect.y > 100 && rect.width > 100) { btns[i].click(); break; }
     }
   }"
   ```
4. Обработать popup "вакансия в другой стране":
   ```javascript
   eval "var btns = document.querySelectorAll('button');
   for (var i = 0; i < btns.length; i++) {
     if (btns[i].textContent.indexOf('Все равно') > -1) { btns[i].click(); break; }
   }"
   ```
5. Клик "Добавить сопроводительное" (eval по textContent, rect.y > 500)
6. Polling textarea (каждые 500мс, timeout 5с):
   ```javascript
   // В eval невозможен async polling, поэтому через повторные вызовы eval
   eval "document.querySelector('textarea') ? 'ready' : 'no_ta'"
   // Повторять каждые 500мс до 10 раз
   ```
7. Если textarea не найдена: SKIP_NO_TEXTAREA
8. Ввод текста: `$NODE $CDP type <tab> "<text>"`
9. Клик "Откликнуться" в модалке (eval, rect.y > 500)
10. Polling "Резюме доставлено" (каждые 500мс, timeout 5с)
11. Если не найдено: screenshot + FAILED_NO_CONFIRMATION
12. Anti-bot check: если на странице "капча", "подтвердите", "подозрительная активность" → FAILED_ANTI_BOT, STOP
13. Throttle: пауза 5-10 сек (random) перед следующим
